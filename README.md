🏏 IPL Win Predictor - The Smart Engine
A high-performance machine learning web application built with Python and Streamlit to predict the winner of an IPL match dynamically at the innings break based on historical match data, venue conditions, and live match context.

🚀 Features
Smart Cricket Logic Engine: Automatically computes batting and chasing teams based on match toss decisions.

Interactive Dashboard: Clean, stadium-themed glassmorphism interface powered by Streamlit and custom CSS.

Dynamic Constraints: Ensures team uniqueness and real-time validation for a seamless user experience.

Pre-trained ML Classification: Utilizes optimized encoders and a trained model to evaluate winning probabilities.

🛠️ Tech Stack
Language: Python

Framework: Streamlit

Machine Learning & Data: Scikit-Learn, Joblib, Pandas, NumPy

Styling: Custom CSS Injection (Glassmorphism UI)

⚙️ Local Setup & Installation
Clone the repository: git clone https://github.com/Parth-210707/Parth.Projects.git

Navigate to folder: cd Parth.Projects

Install dependencies: pip install -r requirements.txt

Run the app: streamlit run app.py

📊 Model Details
The underlying classification model evaluates historical IPL data incorporating features such as team pairings, venue conditions, toss details, and first innings target runs.
